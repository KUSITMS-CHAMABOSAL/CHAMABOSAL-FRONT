# 인터랙션 함정

증상으로 찾습니다. 새로 걸린 문제는 한 줄로 추가하고, 값은 코드 주석에 둡니다.

| 증상                                           | 원인                                                                                                  | 해결                                                                                                                     |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 다른 상태가 바뀔 때 저사양에서 프레임이 튐     | 무거운 SVG(그라디언트 수십 개)가 함께 다시 그려짐                                                     | 그 컴포넌트를 `memo`로 감쌈                                                                                              |
| 탭·필터 전환에서 100ms 넘는 프레임             | `key`로 목록을 다시 마운트함                                                                          | 모두 마운트해 두고 `hidden`만 바꾼 뒤 그리드에 WAAPI 등장 효과                                                           |
| 처음 나타나는 그림이 한 프레임 비어 보임       | 나타나는 순간 이미지를 마운트함                                                                       | SKILL.md 3장 "바뀔 그림은 미리 마운트" 참조                                                                              |
| SVG 자식이 엉뚱한 점을 기준으로 돎             | SVG 원점 기준 변환                                                                                    | `transform-fill origin-center`를 함께 씀                                                                                 |
| 낮은 WebView에서 이동·회전이 안 먹음           | Tailwind v4 `translate-*`, `scale-*`, `rotate-*`는 개별 변환 속성(iOS 14.1, Android WebView 104 이상) | `[transform:...]`나 WAAPI로 바꿈. 🔖 토스 앱 최소 WebView 버전 확인 필요                                                 |
| 12px 안팎의 작은 대상을 누르기 어려움          | 터치 면적이 손가락보다 작음                                                                           | 확대(1.5배) + 반지름 2배 안의 가장 가까운 자리로 붙임                                                                    |
| 넓은 화면에서 양옆에 둥근 쉐도우가 보임        | 375px 기준 배경(타원 빛)을 고정 폭으로 그림                                                           | `preserveAspectRatio="none"` SVG를 `w-[calc(100%*원래폭/375)]`로 가로만 늘리고 360·375·430px에서 비교                    |
| 요소를 줄이거나 옮기자 회색 띠·그림자가 드러남 | 시안 SVG에 다른 레이어로 가려진 쉐도우가 있음                                                         | 사용자에게 확인하고 그 레이어를 지움                                                                                     |
| 쌓이는 모양이 미끄러지거나 어색함              | 더미를 통째로 위로 올리거나 별도 모양을 새로 쌓음                                                     | 기존 더미를 아래 축으로 키우고, 알은 닿을 때 눌렸다 묻히게 함. 닿을 높이는 그 순간 크기와 시안에서 잰 윗면 곡선으로 계산 |
| 끝난 뒤에도 애니메이션 수십 개가 남음          | `fill`로 붙잡힌 WAAPI                                                                                 | SKILL.md 3장 "연타는 막지 않고 받습니다" 참조                                                                            |
